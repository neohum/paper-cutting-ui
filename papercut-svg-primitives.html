100% PURE SVG VECTOR ARCHITECTURE

PaperCut SVG UI Library

Radix UI의 엄격한 WAI-ARIA 접근성 프리미티브를 100% 순수 SVG 다층 페이퍼아트 벡터 그래픽으로 재창조한 차세대 UI 컴포넌트 라이브러리입니다. 단순한 CSS 박스가 아닌, 실제 조각칼로 정밀 절단한 색종이 레이어와 수공예 미싱선, 2-Tier 번트 엄버 그림자가 살아 숨쉽니다.

Creative Aesthetic Prompt:
“Layered paper-cut illustration of [Radix UI Primitives], with overlapping shapes in soft pastel colors, handcrafted textures, subtle shadows between layers, clean vector edges, centered on a matte cream background, whimsical and modern visual storytelling.”
실시간 피드백: 컴포넌트를 클릭하거나 조작해보세요. 대기 중...

01. Button & Toggle

Primitive: Button

350g 밑판 마운트 보드와 상단 0.88px 순백 칼선 림, 클릭 시 3D 단차 압축 피직스를 제공합니다.

02. Switch

Primitive: Switch

음각 도화지 트랙 안에서 수제 종이 셔터가 스프링 탄성으로 좌우 슬라이딩하며 파스텔 색지를 드러냅니다.

03. Checkbox

Primitive: Checkbox

우표 천공 톱니 테두리 위에 나이프 컷 V자 체크마크가 도장처럼 쾅 찍히는 벡터 스탬프입니다.

04. Radio Group

Primitive: RadioGroup

원형 종이 인장 디스크와 방향키(ArrowUp/Down) 키보드 탐색을 완벽히 지원합니다.

05. Slider

Primitive: Slider

조각칼로 파낸 도화지 슬릿 홈을 따라 3D 종이 썸을 마우스/터치로 부드럽게 드래그합니다.

값: 50%

06. Progress

Primitive: Progress

음각 트렌치 안에서 부드럽게 차오르는 파스텔 색지 스트립 게이지입니다.

07. Accordion (Paper Flap)

Primitive: Accordion

접는 선(Crease Line)을 따라 헤더 플랩이 부드럽게 열리며 내부 종이 공예 내용을 노출합니다.

08. Tabs (Manila Index)

Primitive: Tabs

선택된 서류철 인덱스 탭이 앞쪽 레이어로 솟아오르고 비활성 탭은 뒤로 숨겨지는 물리적 겹침을 제공합니다.

09. Card (Die-Cut Ticket)

Primitive: Card

양옆에 반원형 노치가 파인 다이컷 티켓 실루엣과 수공예 미싱선 스티칭을 갖춘 순수 SVG 카드입니다.

10. Dialog & Modal

Primitive: Dialog

도화지를 창문 모양으로 오려낸 다층 섀도우박스 액자 모달을 띄웁니다.

11. Tooltip & Popover

Primitive: Tooltip

마우스를 올리거나 포커스를 맞추면 꼬리표가 오려진 파스텔 종이 태그가 부드럽게 솟아납니다.

12. Select & Dropdown

Primitive: Select

클릭 시 파스텔 색종이 목록이 펼쳐지는 WAI-ARIA combobox 셀렉트입니다.
