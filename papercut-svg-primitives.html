100% PURE SVG VECTOR ARCHITECTURE

PaperCut SVG UI Library

Radix UI의 엄격한 WAI-ARIA 접근성 프리미티브를 100% 순수 SVG 다층 페이퍼아트 벡터 그래픽으로 재창조한 차세대 UI 컴포넌트 라이브러리입니다. 단순한 CSS 박스가 아닌, 실제 조각칼로 정밀 절단한 색종이 레이어와 수공예 미싱선, 2-Tier 번트 엄버 그림자가 살아 숨쉽니다.

Creative Aesthetic Prompt:
“Layered paper-cut illustration of [Radix UI Primitives], with overlapping shapes in soft pastel colors, handcrafted textures, subtle shadows between layers, clean vector edges, centered on a matte cream background, whimsical and modern visual storytelling.”

실시간 피드백: 컴포넌트를 클릭하거나 조작해보세요. 대기 중...

01. Button & Toggle

Primitive: Button

350g 밑판 마운트 보드와 상단 0.88px 순백 칼선 림, 클릭 시 3D 단차 압축 피직스를 제공합니다.

02. Switch

Primitive: Switch

음각 도화지 트랙 안에서 수제 종이 셔터가 스프링 탄성으로 좌우 슬라이딩하며 파스텔 색지를 드러냅니다.

03. Checkbox

Primitive: Checkbox

우표 천공 톱니 테두리 위에 나이프 컷 V자 체크마크가 도장처럼 쾅 찍히는 벡터 스탬프입니다.

04. Radio Group

Primitive: RadioGroup

원형 종이 인장 디스크와 방향키(ArrowUp/Down) 키보드 탐색을 완벽히 지원합니다.

05. Slider

Primitive: Slider

조각칼로 파낸 도화지 슬릿 홈을 따라 3D 종이 썸을 마우스/터치로 부드럽게 드래그합니다.

값: 50%

06. Progress

Primitive: Progress

음각 트렌치 안에서 부드럽게 차오르는 파스텔 색지 스트립 게이지입니다.

07. Accordion (Paper Flap)

Primitive: Accordion

접는 선(Crease Line)을 따라 헤더 플랩이 부드럽게 열리며 내부 종이 공예 내용을 노출합니다.

08. Tabs (Manila Index)

Primitive: Tabs

선택된 서류철 인덱스 탭이 앞쪽 레이어로 솟아오르고 비활성 탭은 뒤로 숨겨지는 물리적 겹침을 제공합니다.

08-B. Layered Paper Craft Tabs (좌우 적층형 3D 종이 카드 탭 덱)

Primitive: LayeredTabs

가로 스크롤 없이 활성 탭을 중심으로 색 카드스톡이 왼쪽·오른쪽으로 계단식으로 겹쳐 쌓이는 100% Pure SVG 다층 탭 덱입니다. 탭 선택 시 부드러운 종이 들림과 물리적 적층 순서 재정렬이 일어납니다.

09. Card (Die-Cut Ticket)

Primitive: Card

양옆에 반원형 노치가 파인 다이컷 티켓 실루엣과 수공예 미싱선 스티칭을 갖춘 순수 SVG 카드입니다.

10. Dialog & Modal

Primitive: Dialog

도화지를 창문 모양으로 오려낸 다층 섀도우박스 액자 모달을 띄웁니다.

11. Tooltip & Popover

Primitive: Tooltip

마우스를 올리거나 포커스를 맞추면 꼬리표가 오려진 파스텔 종이 태그가 부드럽게 솟아납니다.

12. Select & Dropdown

Primitive: Select

클릭 시 파스텔 색종이 목록이 펼쳐지는 WAI-ARIA combobox 셀렉트입니다.

13. Badge & Stamp

Primitive: Badge

우표 톱니 테두리, 티켓 노치, 미싱 점선이 들어간 순수 SVG 종이공예 배지입니다.

14. Input & TextField

Primitive: Input

수제 종이 보드에 오목하게 파낸 음각 슬릿(Cutout Inset) 형태의 SVG 인풋입니다.

15. Avatar

Primitive: Avatar

동심원 미싱 점선과 0.88px 림 라이트가 적용된 순수 SVG 종이 디스크 아바타입니다.

16. Breadcrumb

Primitive: Breadcrumb

낱장의 다이컷 색지 태그와 쉐브론 화살표로 연결된 100% 순수 SVG 브레드크럼입니다.

17. Pagination

Primitive: Pagination

파스텔 스탬프 블록과 미싱 라인이 들어간 순수 SVG 인터랙티브 페이지네이션입니다.

18. Toast Alert

Primitive: Toast

마스킹 와시테이프로 벽면에 부착된 듯한 3D 입체 순수 SVG 팝업 알림입니다.

19. Stepper

Primitive: Stepper

미싱 점선 원형 디스크와 연결 대시선으로 구성된 순수 SVG 단계 표시기입니다.

20. Alert & Callout

Primitive: Alert

파스텔 색지와 테두리 스티치, 좌측 컬러 와시테이프 핀이 결합된 순수 SVG 알림 배너입니다.

21. Table

Primitive: Table

모눈종이 질감과 파스텔 인덱스 헤더 탭이 조화된 순수 SVG 종이 데이터 표입니다.

22. Skeleton Loader

Primitive: Skeleton

종이 도화지를 칼로 오려낸 자리에 빛이 흘러가는 음각 슬릿 순수 SVG 스켈레톤입니다.
