# 수업 게임 (lesson-game)

교사의 아이디어 한 줄을 **성취기준 하나를 연습하는 5~10분짜리 게임**으로 바꾼다. 게임의 핵심 동작은 곧 학습
행동이다. "지시약 반응으로 분류하기"가 목표라면 플레이어는 지시약을 넣고 색을 보고 분류한다. 학습 내용을
점수판 옆에 붙인 일반 게임을 만들지 않는다.

게임은 실행기(`assets/runtime.js`)와 게임 스크립트(`game.js`), 화면(`index.html`) 세 파일로 된다. 실행기는
화면 전환(시작 → 놀이 → 정리), 그리기 루프, 키 입력, 시드 난수, 코드로 만든 효과음, 움직임 줄이기 설정,
화면낭독기 알림, 검사용 연결(`window.lessonGame`)을 맡는다. 게임 스크립트는 내용, 규칙, 그림, 정리를 맡는다.

## 입력

교사에게 아래를 받는다. 빠진 것이 있으면 한 번에 모아서 묻고, 학년과 아이디어만 있어도 시작한다.

```
아이디어: (예) 용액에 지시약을 넣어 산성·염기성을 가려내는 탐정 놀이
학년: (예) 초등 5학년
성취기준 코드: (선택) [6과09-01]
참고: (선택) 이미지 파일, 또는 영상 설명 "공이 통에 떨어지면 색이 바뀌는 장면"
수업 시간: (선택) 10분
```

- 참고 영상은 볼 수 없다. 교사의 설명에서 **카메라 시점, 한 가지 동작, 화면 분위기**만 뽑는다. 이미지가 있으면
  열어 보고 배치·색만 참고한다. 등장인물·로고·레벨 구성을 기존 게임이나 영화에서 가져오지 않는다.
- 학생 이름, 학번, 얼굴 사진 같은 개인정보는 입력으로 받지 않고 게임 안에서도 묻지 않는다. 학생은 계정이 없다.
  게임은 결과를 저장하거나 보내지 않는다.

## 순서

1. **설계 카드를 먼저 쓴다.** `game.js` 맨 위 주석에 한국어로 적는다. 코드보다 먼저다.
   - 성취기준: 코드와 요지. `kr-leanmap` 의 `search_standards` 도구가 있으면 그것으로 코드를 확인한다. 없으면
     교사가 준 코드를 쓰고, 확인하지 못했다고 README 에 적는다. 성취기준 원문은 옮겨 적지 않고 요지만 쓴다.
   - 핵심 동작: 학습 행동 그대로 (아래 *학습 행동 → 게임 동작* 표).
   - 이기는 조건, 틀렸을 때의 되먹임(정답을 주지 말고 다시 관찰할 곳을 가리킨다), 판 수, 걸리는 시간.
   - 정리 질문 3개: 기억(사실) 1, 이해(이유) 1, 생각 넓히기 1. 답은 접어 둔다.
2. **폴더를 만든다.** 이 스킬의 `assets/index.template.html` → `index.html`, `assets/runtime.js` → `runtime.js`,
   `assets/game.template.js` → `game.js` 로 복사한다. 이름은 게임 주제로 지은 폴더 하나에 둔다.
3. **내용을 쓴다.** 교과 사실은 `game.js` 의 `ITEMS` 같은 한 곳에만 둔다. 교과서에 나오는 예와 표현을 쓰고,
   애매한 사례(약산·중성 등)는 빼거나 정리 질문으로 돌린다. 학년 수준의 낱말을 쓴다.
4. **화면을 채운다.** `index.html` 의 `{{…}}` 를 모두 바꾼다. 놀이 영역에는 실제 `<button>` 을 두고, 같은 일을
   하는 키를 `keys` 에 묶는다. 색만으로 정보를 주지 않는다(색 변화는 글로도 적고 `game.announce` 로 알린다).
5. **그림과 소리.** 먼저 캔버스 코드로 그린다(도형, 그라데이션, 간단한 입자). 그림 파일이 꼭 필요하면
   `references/asset-sources.md` 의 출처에서만 가져와 `assets/` 에 넣고 `credits.md` 에 한 줄씩 적는다. 소리는
   실행기의 `game.sound.play('tap'|'ok'|'no'|'win')` 를 쓰고, 파일이 필요하면 같은 규칙을 따른다. 생성형 이미지
   API, 유료 서비스, API 키, CDN, 웹 글꼴, 아이콘 글꼴, 이모지를 쓰지 않는다.
6. **정리 화면을 만든다.** `enterDebrief` 에서 채운다: 이번 판의 결과 표(무엇을 했고 무엇을 봤는지), 정리 질문
   3개(`<details>` 로 답 접기), 교사용 한 줄(다음 차시 연결이나 실제 실험 안전 지도), CC-BY 자료를 썼다면 출처.
7. **이기는 길을 쓴다.** `nextTestAction(game, mode)` 가 지금 상태에서 다음 실제 입력을 돌려준다. `'pointer'`
   일 때는 `{ click: 선택자 }`, `'keyboard'` 일 때는 `{ key: 'Digit1' }`, 애니메이션 중에는 `{ wait: ms }`,
   정리 화면이면 `null`. 정답을 바로 바꾸는 지름길 함수를 만들지 않는다. 검사는 학생과 같은 버튼을 누른다.
8. **검사한다.**
   ```
   node "<스킬 폴더>/scripts/check-game.cjs" <게임 폴더> <게임 폴더>/check
   ```
   playwright 를 못 찾으면 `NODE_PATH=<playwright 가 있는 node_modules>` 를 붙인다. 휴대폰 390px(터치·포인터
   경로)과 노트북 1280px(키보드만)로 각각 끝까지 플레이하고 `report.json` 과 스크린샷 6장을 남긴다. 종료코드가
   0 이어야 한다. **스크린샷을 직접 열어 본다**: 글자가 잘리거나 겹치는지, 캔버스 그림이 읽히는지, 정리 화면이
   보이는지. 고치고 다시 검사한다(최대 3회).
9. **한 장으로 묶는다.**
   ```
   node "<스킬 폴더>/scripts/make-single-file.cjs" <게임 폴더> <게임 폴더>/<주제>.html
   ```
   묶은 파일도 `check-game.cjs <주제>.html` 로 한 번 더 검사한다.
10. **넘긴다.** 폴더, 한 장짜리 HTML, `README.md`(교사용: 성취기준, 걸리는 시간, 진행 방법, 정리 발문, 확인하지
    못한 것), `credits.md`, `references/checklist.md` 를 채운 사본(`checklist.md`), 검사 결과 숫자.

## 학습 행동 → 게임 동작

| 성취기준 동사 | 게임 동작 | 예 |
|---|---|---|
| 분류하다 | 관찰 도구를 써서 증거를 모은 뒤 바구니에 나눠 담기 | 지시약 → 산성/염기성 |
| 비교하다·측정하다 | 두 대상을 같은 도구로 재고 더 큰/작은 쪽 고르기 | 그림자 길이, 분수 크기 |
| 예상하다·추론하다 | 먼저 예상을 고르고, 실행해 결과를 본 뒤 맞았는지 확인 | 섞으면 어떻게 될까 |
| 순서를 정하다 | 카드를 끌거나 화살표 키로 순서 맞추기 | 한살이, 역사 사건 |
| 짝짓다·대응시키다 | 두 줄을 이어 짝 맞추기 | 낱말-뜻, 나라-수도 |
| 만들다·조합하다 | 부품을 골라 조건을 만족하는 것 완성 | 전기 회로, 문장 성분 |
| 계산하다 | 움직이는 목표에 맞는 수를 골라 맞히기 | 어림셈, 받아올림 |

틀린 답을 고르면 점수를 깎는 것보다 **다시 볼 곳**을 가리킨다. 처음에 맞힌 수와 다시 해서 맞힌 수를 따로 센다.
증거가 모자란 답(예: "변화 없음" 하나만 보고 분류)은 맞든 틀리든 받지 않고 더 관찰하게 한다. 찍어서 맞히는 길을 막는다.

## 지킬 것

- **목표 → 놀이 → 정리.** 시작 화면에 학습 목표, 끝에 정리 화면. 정리 없이 끝나는 게임은 넘기지 않는다.
- **오프라인.** 폴더 하나 또는 HTML 한 장, 일반 `<script src>`. `type="module"`, import map, `fetch()` 로 읽는
  JSON 은 file:// 에서 막히므로 쓰지 않는다. 외부 주소 요청 0 건.
- **의존성 없음.** 캔버스 2D 기본. 라이브러리가 꼭 필요하면 그 파일을 폴더에 넣고 라이선스를 credits.md 에 적는다.
- **접근성.** 누를 수 있는 것은 모두 44×44px 이상, 키보드로 전부 할 수 있고 단축키를 화면에 적는다. 포커스가
  보인다. 색만으로 정답을 알리지 않는다. `prefers-reduced-motion` 을 따른다(실행기의 `game.tween` 이 처리).
- **휴대폰.** 390px 폭에서 가로 스크롤 없음. 캔버스는 화면 높이의 절반 안팎.
- **개인정보 없음.** 이름 입력란, 저장, 전송, 분석 도구 없음.
- **이름은 우리 것.** 파일·함수·변수 이름은 수업과 게임 내용을 설명한다. 다른 저장소의 이름을 가져오지 않는다.
