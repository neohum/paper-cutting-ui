# 넘기기 전 점검표

게임 폴더에 `checklist.md` 로 복사해 칸을 채운다. 숫자는 `check/report.json` 에서 **읽어서** 적는다.

## 학습 목표

- [ ] 성취기준 코드: ______ (확인 방법: 도구 / 교사 제공 / 미확인)
- [ ] 시작 화면에 학습 목표가 한 문장으로 있다
- [ ] 게임의 핵심 동작이 성취기준의 동사와 같다 (동사: ____ → 동작: ____)
- [ ] 교과 사실을 교과서·교육과정과 대조했다. 애매한 사례는 뺐거나 정리 질문으로 돌렸다
- [ ] 틀렸을 때 정답을 주지 않고 다시 볼 곳을 가리킨다

## 정리 (debrief)

- [ ] 정리 화면에 이번 판의 결과(한 일과 관찰)가 표로 나온다
- [ ] 정리 질문 3개: 사실 1, 이유 1, 생각 넓히기 1. 답은 접혀 있다
- [ ] 교사용 한 줄: 다음 차시 연결 또는 실제 활동 안전 지도
- [ ] 다시 하기 버튼이 있고 새 순서로 시작한다

## 접근성

- [ ] 누를 수 있는 모든 것 44×44px 이상 (report: smallTargets = 0)
- [ ] 키보드만으로 시작부터 정리까지 간다 (report: laptop-1280 reachedDebrief = true)
- [ ] 단축키를 화면에 적었다
- [ ] 포커스 테두리가 보인다
- [ ] 색만으로 정보를 주지 않는다 (색 변화를 글로도 적고 낭독기로 알린다)
- [ ] 움직임 줄이기 설정에서 애니메이션이 바로 끝난다

## 오프라인·배포

- [ ] 외부 요청 0 건 (report: externalRequests = 0, 두 화면 모두)
- [ ] 콘솔 오류 0 건 (report: consoleErrors = 0)
- [ ] `type="module"`, import map, fetch, CDN, 웹 글꼴, 아이콘 글꼴 없음
- [ ] 390px 폭에서 가로 스크롤 없음 (report: overflowX = 0)
- [ ] 한 장짜리 HTML 도 검사를 통과했다
- [ ] 크기: 폴더 ____ KB, 한 장 ____ KB (2MB 이하 권장, 교실 LAN·휴대폰)

## 개인정보·출처

- [ ] 이름·학번·사진 입력 없음, 저장(localStorage 포함)·전송 없음
- [ ] credits.md 가 있고 모든 파일 자료가 한 줄씩 적혀 있다 (코드로만 그렸다면 그렇게 적었다)
- [ ] CC-BY 자료가 있으면 정리 화면에도 출처가 보인다
- [ ] 파일·함수 이름이 수업 내용을 설명한다

## 눈으로 본 것

- [ ] 스크린샷 6장을 열어 봤다: 글자 잘림 __, 겹침 __, 캔버스 그림이 읽힘 __, 정리 화면 보임 __
