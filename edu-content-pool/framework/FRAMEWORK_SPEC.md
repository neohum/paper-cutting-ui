# 창체 모듈 체계도 — 형식과 원칙

창체(안전·법정·계기·자율) 수업을 '차시 하나 = 고정 묶음'으로 만들지 않고, **학년군·주제마다 도입·활동·정리 모듈을 여러 개** 만들어 조합한다. 교사는 주제를 고른 뒤 학급에 맞는 도입 1개 + 활동 1~3개 + 정리 1개를 골라 40분(중 45·고 50분) 수업을 꾸린다. 의무 시수는 학년별 '추천 조합'으로 채운다.

## 학년군과 학습 방식 (모든 영역 공통 기준)

| 학년군 | 학습자 특성 | 써야 할 방식 | 피할 것 |
|---|---|---|---|
| 초1-2 | 글을 거의 못 읽음, 주의 10분 안팎, 구체물·몸 | 그림 장면 고르기, 소리로 읽어 주기(문항 짧게, 카드 6자 안팎), 따라 하기·동작, 역할놀이, 노래·구호, 좋아요/안돼요 고르기 | 긴 글, 추상어, 법·제도, 3단계 넘는 순서 |
| 초3-4 | 구체적 조작기, 규칙 이해, 짝 활동 가능 | 상황 판단(그림+짧은 글), 차례 정하기, 고른 이유 말하기, 짝 토의, 간단한 표·그림그래프 | 법 조문, 통계 해석, 긴 글쓰기 |
| 초5-6 | 원인·결과 추론, 자기 점검 가능 | 사례 원인과 결과, 자기 점검표, 작은 실천 계획, 간단한 자료(그래프) 읽기, 모둠 토의 | 법 조문 번호, 형량, 성인 상황 |
| 중 | 추상적 사고 시작, 또래 영향 큼 | 사례 분석, 딜레마 토의(갈림길·결과), 자료·그래프 해석, 짧은 글쓰기(기준표 자기 평가), 역할극 대본, 캠페인 만들기 | 카드 분류만 하는 차시, 유치한 장면 |
| 고 | 성인기 준비, 권리·책임·제도 | 법·제도와 실제 자료 분석, 토론(찬반 근거), 제안서·캠페인 설계, 성찰 글, 진로·자립 연결, 딜레마 결과 추적 | 단순 고르기 반복, 초등식 장면 |

교구는 학년군 안에서 다양하게: 카드 계열(mindmap·story·emotion·timeline·wordcards·sortboard)만이 아니라 chart(자료), map, timer, kitchen, economy, body, 새 교구 dilemma(결과가 이어지는 갈림길 상황)·rubric-writing(기준표로 자기 평가하는 글쓰기). 한 학년군의 모듈 가운데 카드 계열이 60%를 넘지 않게 한다.

## 체계도 데이터 (`framework/<영역묶음>.json`)

```json
{
  "domains": [
    {
      "code": "saf-life", "title": "생활안전", "area": "안전교육",
      "basis": "학교안전교육 실시 기준 고시 제2023-33호 별표 1·2",
      "hours": { "1": 12, "2": 12, "3": 12, "4": 12, "5": 12, "6": 12, "7": 10, "8": 10, "9": 10, "10": 10, "11": 10, "12": 10 },
      "bands": {
        "초1-2": {
          "topics": [
            { "id": "saf-life.e12.home", "title": "집 안 위험한 물건", "grades": [1, 2],
              "objective": "…", "concepts": ["…"], "misconceptions": ["…"], "source": "별표 2 초등 생활안전 1" }
          ],
          "modules": [
            { "id": "saf-life.e12.home.intro.picture", "type": "intro", "topic": "saf-life.e12.home",
              "method": "그림 장면에서 위험한 곳 찾기", "tool": "emotion", "minutes": 6,
              "brief": "부엌 그림 장면을 보고 위험한 물건을 눌러 고른다(소리로 읽어 줌).",
              "levels": { "easy": "…", "base": "…", "challenge": "…" } }
          ],
          "sequences": [
            { "grade": 1, "lessons": [ { "n": 1, "topic": "saf-life.e12.home", "intro": "…", "activities": ["…"], "wrap": "…" } ] }
          ]
        }
      }
    }
  ]
}
```

- **topics**: 학년군 주제. 공식 근거(고시 별표 2·법령·교육과정 원문 — `sources/changche/research-*.md`)의 세부 항목에서 고르고 `source` 에 적는다. 학년군 안에서 학년이 다르면 `grades` 로 나눈다(같은 주제를 두 학년이 다른 깊이로 쓰면 주제를 둘로).
- **modules**: 주제마다 **도입 2개 이상, 활동 3개 이상, 정리 2개 이상**. 서로 다른 방식이어야 한다(같은 교구·같은 방식 반복 금지). `levels` 는 쉬움·기본·도전에서 무엇이 달라지는지 한 줄씩.
- **sequences**: 학년마다 의무 시수(`hours`)만큼의 추천 차시 조합. 각 차시 = 도입 1 + 활동 1~3(합 27분 안팎) + 정리 1. 같은 학년 안에서 모듈을 되풀이하지 않는다.
- 사실·수치·법 조항은 근거 파일에 있는 것만. 학년군 기준표의 '피할 것'을 지킨다. 피해 경험을 묻는 모듈 금지, 자살예방은 방법 묘사 금지, 계기교육은 정치적 중립.
