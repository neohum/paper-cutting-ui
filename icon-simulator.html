아이콘 규격별 듀얼 디자인 시뮬레이션 스튜디오

가독성 한계 이하인 10px~14px는 지원하지 않으며, 16px부터 256px까지 완벽하게 지원합니다. 16~28px 구간(fi fi-rr 정밀 라인 스튜디오)과 32~256px 구간(3D 레이어드 페이퍼 아트 스튜디오)은 디자인 관점(UI 글리프 가독성 vs 3D 페이퍼 디오라마 질감)이 완전히 다르므로 두 개의 독립된 전문 스튜디오로 완벽하게 분리되어 운영됩니다.

수학적 벡터와 인터랙티브 코드의 진화 (The Renaissance of Vector & Code)

“처음엔 AI가 당연히 수학계산 방식인 벡터 방식부터 올 줄 알았는데, 픽셀 베이스의 비트맵 방식이 먼저 오고, 이제야 벡터 방식이 빠르게 발전하는 것 같아요. 벡터 형식인 SVG가 실상 XML 기반의 '코드'(Code) 인데, 최근 이 부분에서 비약적인 발전이 있기 때문인 것 같아요.
제품 이미지를 넣어주거나, 설명을 하면, 라인 형식으로 인터렉티브한 코드 파일을 만들어 줍니다. :) SVG로 다운도 가능하여 웹사이트에 넣기에 안성맞춤입니다.”

1. fi fi-rr 정밀 벡터 라인 캔버스 16px ~ 28px

디자인 관점: UI 글리프 가독성 집중. 0.88px 진회색(#423D39) 극세 라인, 8% 파스텔 워시, 3D 그림자 차단으로 마이크로 컴포넌트(버튼·인풋·탭바)의 또렷한 가독성을 제공합니다.

2. 3D 레이어드 페이퍼 아트 캔버스 16px ~ 256px

디자인 관점: 종이 공예의 디오라마적 공간감. 16px부터 256px까지 외곽선 없는 순수 다층 색지(Mint·Peach·Lavender)와 3D 입체 드롭섀도우로 카드·모달·배너·쇼케이스의 예술적 깊이를 연출합니다.

실시간 동적 스케일링 듀얼 캔버스 동시 구동 중

왼쪽 [캔버스 1: ≤28px fi-rr 극세 라인]과 오른쪽 [캔버스 2: 16px~256px 3D 페이퍼 컬러]가 동시에 실시간 렌더링되며, 각각의 슬라이더 조작 및 루페 확대를 통해 최적화된 시각적 차이를 직접 검증할 수 있습니다.

인터랙티브 SVG 벡터 코드 & 원클릭 다운로드 스튜디오

벡터 형식인 SVG는 실상 XML 기반의 '살아있는 코드(Code)'입니다. 라인 형식으로 인터랙티브한 코드 파일을 생성하고, 웹사이트에 바로 넣을 수 있는 독립형 SVG 파일로 즉시 다운로드하세요.

fi fi-rr Line Art 0.88px 극세 진회색 라인의 정밀한 가독성

SVG 벡터 본연의 수학적 정밀도를 살린 0.88px 극세 선 두께와 세련된 진회색(#423D39), geometricPrecision 렌더링으로 작은 크기에서도 뭉침 없이 날렵하고 또렷하게 빛납니다.

Aesthetic Wash 아름다운 파스텔 페이퍼 틴트

차가운 흑백 선화가 아니라, 13%의 맑은 수채화 색지 틴트(민트·피치·라벤더)가 감돌아 따뜻하고 우아한 종이 예술의 품격을 간직합니다.

Zero Dependency 외부 CSS 없는 독립형 SVG

다운로드된 SVG는 인라인 속성이 완벽히 패키징되어 있어 외부 CSS 없이도 피그마, 리액트, 뷰, 웹사이트 어디서나 동일하게 작동합니다.
